# AI Mathematical Olympiad — Mathematical Reasoning Experiments

## Problem

The AI Mathematical Olympiad (AIMO) challenge focuses on building systems that can solve challenging mathematical problems. Our work explored how model choice, prompting, and inference configurations affected the answers generated by language models.

We experimented with Qwen- and DeepSeek-based models, including 7B and 14B configurations, and reviewed their outputs to understand how reliably they handled competition-style maths questions.

## Results

- **Score:** 31.8%
- **Rank:** 531 out of 2,122 teams
- **Overall placement:** Top 25% of teams

These results placed our solution in the top quarter of the field. Our experiments explored different model and inference setups, but they did not establish a notable improvement from one configuration over another. The results should be read as our team's challenge outcome, not as evidence that a particular model setting was definitively better.

## Running the code

Running these notebooks requires substantial inference setup, including compatible GPU resources, model files, and the required libraries and configuration. Some experiments use vLLM and multi-GPU inference, so they may not run directly on a standard laptop.

The notebooks can be adapted to run through **Google Colab** with suitable GPU access and setup. Cloud GPU support, including services such as **Modal**, may also be used to provide the resources needed for inference. Before running an experiment, review its model paths, dependencies, and hardware requirements.

## What we learned

These experiments highlighted the importance of reliable answer checking, broader question coverage, and consistent settings when comparing models. A model completing an inference run does not by itself show that its answers are correct or that a configuration performs better. More controlled testing would be needed to establish such improvements.
